# Google-sheets-assignment-IBM
📊 Sales Data Analysis Using Google Sheets

📌 Project Overview

This project focuses on analyzing sales order data using Google Sheets as part of my BBA in Business Analytics & AI with IBM.

The objective was to organize sales data, perform basic statistical analysis, identify sales trends, and create visualizations to derive meaningful business insights.

This project demonstrates how spreadsheet-based analytics can help transform raw business data into actionable information for decision-making.

🎯 Objectives

Analyze sales performance across different product categories.

Calculate total sales and average order value.

Compare sales performance across cities.

Explore payment methods and order types.

Identify high-value orders.

Present insights using charts and visualizations.

🛠️ Tools & Technologies

Google Sheets — Data organization, calculations, analysis, and visualization.

Spreadsheet formulas — Summary statistics and sales calculations.

Charts and graphs — Visual representation of sales insights.

📁 Dataset Description

The dataset contains 10 sample sales orders with the following fields:

Column

Description

Unique order identifier

Number of units ordered

Total (₹)

Total value of the order

Order Type

Order classification, such as Regular or High Value

⚙️ Methodology

Data organization: Arranged the sales records into a structured table.

Data calculation: Used spreadsheet formulas to calculate order totals and summary statistics.

Sales analysis: Examined sales by category and city.

Order classification: Reviewed the order types and identified high-value orders.

Data visualization: Created charts to communicate the results clearly.

Insight generation: Summarized the findings to understand the sales performance.

📐 Key Formulas

Examples of spreadsheet formulas used or applicable to this analysis:

1. Calculate total order value

=Price_Cell*Quantity_Cell

2. Calculate total sales

=SUM(Total_Range)

3. Calculate average order value

=AVERAGE(Total_Range)

4. Count orders

=COUNTA(Order_ID_Range)

5. Identify high-value orders

=IF(Total_Cell>5000,"High Value","Regular")

Note: Replace the example cell references and ranges with the actual references in your spreadsheet.

📊 Key Findings

Based on the analysis performed in the spreadsheet:

Total Sales: ₹73,849

Average Order Value: ₹7,384.90

Orders Analyzed: 10

High-Value Orders: 6 orders with a total value above ₹5,000

Top-Performing Category: Electronics contributed the largest share of total sales.

The visualizations also compare category-wise sales and city-wise sales, helping identify differences in sales contribution.

📈 Visualizations

The project includes:

These visualizations make it easier to interpret the data and communicate business findings.

Electronics is the leading category by sales contribution in this sample.
